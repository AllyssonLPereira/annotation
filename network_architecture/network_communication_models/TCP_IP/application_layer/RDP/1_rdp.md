### RDP - Remote Desktop Protocol


O Remote Desktop Protocol (RDP) foi criado pela Microsoft. Ele usa um modelo cliente-servidor no qual o cliente pode se conectar a um servidor RDP executado em um sistema remoto para exibir a interface gráfica do usuário do dispositivo remoto. 

Os servidores e clientes RDP estão incluídos no Windows e estão disponíveis para OS X, Linux e Unix via xrdp, que é uma implementação gratuita e de código aberto do servidor Microsoft RDP. 

Outros sistemas operacionais também podem executar essas funções. Por exemplo, no macOS, a funcionalidade de acesso remoto é fornecida pelo recurso de compartilhamento de tela, que é baseado no Virtual Network Computing (VNC). 

Qualquer cliente VNC pode se conectar a um servidor de compartilhamento de tela. O VNC é um produto freeware que é semelhante em funcionalidade ao RDP e funciona na porta 5900.
