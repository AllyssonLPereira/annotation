## Antivírus

O uso de produtos antivírus é fortemente recomendado como uma prática de segurança.

Existem vários produtos antivírus disponíveis e muitos podem ser implantados como parte de uma solução corporativa que se integra a vários outros produtos de segurança.

Os sistemas antivírus tentam identificar malware com base na assinatura conhecida ou detectando atividade anormal em um sistema. Essa identificação é feita com vários tipos de scanners, reconhecimento de padrões e algoritmos avançados de aprendizado de máquina.

O antimalware agora vai além da simples proteção contra vírus, pois as soluções modernas buscam oferecer uma abordagem mais holística para detectar rootkits, ransomware e spyware. Muitas soluções de endpoint também incluem firewalls de software e sistemas IDS ou IPS.
